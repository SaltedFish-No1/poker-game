# 牌局大厅 UI/UX 规范

> 说明：原计划从 Claude Design 项目导入《基础控件展示页.dc.html》《扑克牌牌面.dc.html》，
> 但远程执行环境无法完成 claude_design MCP 的交互式授权。本规范为自行制定的等价物，
> 结构与两份设计文件一一对应；设计令牌集中在 `client/src/design/tokens.css`，
> 拿到设计稿后只需替换 token 值即可完成对齐。
> 前端提供在线展示页：应用内访问 `#/design`（对应两份设计文件的实现）。

## 1. 设计原则

1. **桌面即舞台**：深色牌桌氛围（墨绿毛毡 + 金色点缀），牌面是唯一的高亮白色元素，保证视觉焦点始终在牌上。
2. **状态即时可读**：轮到谁、剩几张、什么牌型，不需要文字说明也能一眼读出（高亮描边、徽章、计数气泡）。
3. **操作低成本**：核心操作（出牌/过/提示/叫分）固定在底部主操作区，按钮 ≥ 40px 高，移动端可点。
4. **可扩展**：所有玩法共享同一套控件与牌面组件；新增玩法只新增桌面布局，不新增控件样式。

## 2. 设计令牌（Design Tokens）

定义于 `client/src/design/tokens.css`，全部以 CSS Custom Properties 暴露。

### 2.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--color-bg` | `#0c1512` | 页面底色（近黑墨绿） |
| `--color-felt-1/-2` | `#1d4a38` / `#0f2a20` | 牌桌毛毡径向渐变 |
| `--color-surface` | `#152420` | 卡片 / 面板 |
| `--color-surface-2` | `#1d322b` | 面板悬浮层 / hover |
| `--color-border` | `rgba(255,255,255,.09)` | 描边 |
| `--color-text` | `#eef4f1` | 主文字 |
| `--color-text-dim` | `#93aca2` | 次级文字 |
| `--color-primary` | `#e8b93c` | 主操作（金） |
| `--color-primary-hover` | `#f5cc5e` | 主操作 hover |
| `--color-on-primary` | `#2b2105` | 金底上的文字 |
| `--color-accent` | `#3ecf8e` | 成功 / 轮到你 / 在线 |
| `--color-danger` | `#e05a4e` | 危险 / 地主标记 / 错误 |
| `--color-info` | `#5ea8ff` | 链接 / 信息 |
| `--suit-red` | `#d3392f` | 红花色（♥ ♦） |

### 2.2 字体

- 字族：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", system-ui, sans-serif`；牌面点数使用 `"Georgia", serif` 增加牌面质感。
- 字号阶梯：12 / 13(正文辅) / 14(正文) / 16 / 18(小标题) / 22(标题) / 28(大标题)。
- 行高 1.5；数字使用 `font-variant-numeric: tabular-nums`。

### 2.3 间距 / 圆角 / 阴影

- 间距基数 4px：`--space-1..8` = 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。
- 圆角：`--radius-s` 8、`--radius-m` 12、`--radius-l` 16、`--radius-pill` 999。
- 阴影：`--shadow-1`（面板）、`--shadow-2`（弹层）、`--shadow-card`（扑克牌）。
- 动效：`--dur` 160ms，`ease-out`；选牌抬起 120ms。

## 3. 基础控件（对应《基础控件展示页》）

所有控件实现于 `client/src/ui/`，展示页 `#/design`。

### 3.1 Button

- 变体：`primary`（金，主操作）、`secondary`（描边面板色）、`ghost`（无底）、`danger`。
- 尺寸：`sm` 32px / `md` 40px / `lg` 48px 高；圆角 `--radius-pill`；`disabled` 时透明度 0.45 且禁用指针。
- 主操作一屏至多一个 primary。

### 3.2 Input

- 高 40px，底色 `--color-surface-2`，1px 描边，聚焦时描边 `--color-primary` + 外发光。
- 错误态描边 `--color-danger`；占位符颜色 `--color-text-dim`。

### 3.3 Panel / Card

- 底色 `--color-surface`，圆角 `--radius-l`，内边距 `--space-5`，描边 + `--shadow-1`。

### 3.4 Badge / Tag

- 高 22px 胶囊；语义色：金（地主/房主）、绿（在线/轮到）、红（断线/地主）、灰（默认）。

### 3.5 Modal

- 遮罩 `rgba(0,0,0,.55)` + 8px 模糊；面板宽 ≤ 420px，圆角 `--radius-l`，`--shadow-2`，进场 160ms 缩放淡入。

### 3.6 Segmented（分段选择）

- 用于「单人 / 多人」模式选择；选中段底色 `--color-primary`、文字 `--color-on-primary`。

### 3.7 Toast

- 顶部居中，深色面板 + 语义色左边条，2.4s 自动消失；错误提示统一走 Toast，不打断操作。

## 4. 扑克牌牌面（对应《扑克牌牌面》）

实现于 `client/src/components/PlayingCard.tsx`。

- **比例**：宽:高 = 5:7；默认 `md` 68×95px，`sm` 46×64（对手/历史区），`lg` 80×112（结算展示）。
- **牌面**：底色 `--card-face`，圆角 8px，1px `rgba(0,0,0,.15)` 描边 + `--shadow-card`。
- **角标**：左上角竖排「点数 + 花色」，点数字体 Georgia Bold；10 使用 "10" 不缩写。
- **中心花纹**：单个大花色符号（简化牌面，非全 pip 布局），透明度 0.9。
- **花色色彩**：♥ ♦ 用 `--suit-red`；♠ ♣ 用 `--suit-black`。
- **王牌**：竖排「大王」（红）/「小王」（黑），中心 ★ 符号；无花色角标。
- **牌背**：`--color-primary` 描边双线框 + 菱形格纹（45° 重复线性渐变），中心 ♠ 标志。
- **手牌扇形**：横向重叠排列，重叠 26px（sm 18px）；hover 上浮 6px；**选中态上移 14px + 金色描边 + 阴影加深**。
- **可交互性**：仅轮到自己且对局进行中时牌可点击；不可交互时降低亮度 6%。

## 5. 页面与交互流

### 5.1 大厅

- 顶部：产品名 + 玩家昵称（可改）+ AI 状态徽章（大模型 AI / 规则 AI）。
- 玩法卡片栅格：可玩玩法金色「可开局」徽章，未上线显示「敬请期待」且不可点。
- 房间列表：房名、玩法、人数 x/y、状态（等待中/游戏中）、加入按钮；空态引导创建房间。
- 创建房间弹窗：玩法（仅可玩）、房名、模式（单人=秒开 AI 局 / 多人=好友联机）。

### 5.2 房间（等待）

- 座位环形排布，空位显示「+ 添加 AI」（房主）；房主可开始、成员可离开。
- 人数不足时开始按钮自动补 AI。

### 5.3 斗地主牌桌

- 布局：上左 / 上右为对手（相对座位：下家在右、上家在左），中央为公共区（底牌、倍数、状态），底部为自己（手牌 + 操作区）。
- 叫分阶段：底部操作区显示「不叫 / 1分 / 2分 / 3分」（低于当前最高分的选项禁用）；各家叫分以气泡显示。
- 出牌阶段：轮到的座位头像金色呼吸描边；上一手牌显示在对应座位旁；自己操作区「提示 / 过 / 出牌」，不能过时「过」禁用；非法选牌点「出牌」时 Toast 报错并保留选择。
- AI 回合显示「思考中…」点点动画（约 0.8s 起）。
- 结算弹窗：胜负、春天/反春、倍数明细、三家分数（正绿负红）；房主「再来一局」、成员「返回大厅」。

### 5.4 断线与接管

- 对局中玩家离开/断线：座位标记「已断线·AI 接管」，AI 续打；房间无真人时销毁。

## 6. 业务弹窗（对应《好友申请与加倍确认弹窗》）

实现于 `client/src/styles/dialogs.css`，展示页 `#/design` 可预览。

- **加倍确认弹窗**：标题「是否加倍？」；说明本人身份（地主加倍对两位农民生效，农民只对地主生效）；
  「当前倍数 ➜ 加倍后」双卡片对比（加倍后红色强调）；10 秒圆形倒计时（呼吸动画），
  超时自动按「不加倍」处理；按钮：不加倍（secondary）/ 加倍 ×2（primary）。
- **好友申请弹窗**：申请人卡片（头像 + 昵称 + 说明文案）；按钮：拒绝（ghost）/ 同意（primary）；
  多个申请排队依次展示。
- **好友列表**：胶囊行（在线状态点：绿=在线带光晕，灰=离线）；空态给出引导文案。

## 7. 牌桌特效（对应《斗地主××特效》系列 +《特效总览》）

实现于 `client/src/styles/effects.css`，触发逻辑 `components/Effects.tsx`，
`#/design` 特效总览区可逐个点击预览。

| 特效 | 触发 | 表现 |
|---|---|---|
| 发牌动画 | 进入叫分阶段 | 手牌逐张自右上飞入（45ms/张 级联） |
| 底牌翻牌 | 地主确定 | 3 张底牌依次 rotateY 翻入 |
| 叫分/过牌气泡 | 表态更新 | 弹性 pop-in |
| 叫地主 | 地主揭晓 | 👑 皇冠坠落 + 金色横幅「××当上地主」 |
| 加倍 | 任意座位加倍 | 💰「加倍 ×2」弹跳横幅 |
| 顺子 / 连对 | 打出对应牌型 | 流光扫字横幅（⚡ / 🔗） |
| 三带一 / 三带二 | 打出对应牌型 | 🎯 弹跳横幅 |
| 飞机 | 打出飞机 | ✈️ 横穿全屏 + 横幅 |
| 炸弹 | 打出炸弹 | 💥 红色横幅 + 全屏震动 0.5s |
| 王炸 | 打出王炸 | 🚀 火箭升空 + 红色横幅 |
| 要不起 | 轮到自己且无牌可压 | 红字摆动提示，1.5s 后自动过牌 |
| 认输 | 认输结算 | 红色斜置印章盖入结算弹窗 |
| 托管 | 开启托管 | 金色「托管中」徽章呼吸 + 操作区替换为取消托管 |
| 胜负结算 | 对局结束 | 标题弹入（胜=金色 + 彩带雨，负=灰色）|

全屏特效层 `position: fixed` + `pointer-events: none`，单次约 1.5–1.7s 自动消失，不阻塞操作。

## 8. 可访问性 / 响应式

- 交互元素最小命中区 40×40；文字对比度 ≥ 4.5:1（金色按钮上使用深色文字）。
- 桌面优先，≥ 768px 三列布局；< 768px 时对手信息压缩为顶部两个胶囊，手牌重叠加大。
